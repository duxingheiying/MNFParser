# Public references

- Hexagon, *Adams Flex User Guide*: describes MNF contents as geometry/connectivity, nodal mass and inertia, mode shapes, and generalized mass/stiffness. https://documentation-be.hexagon.com/bundle/Adams_2024.1_Adams_Flex_User_Guide/raw/resource/enus/Adams_2024.1_Adams_Flex_User_Guide.pdf?save_local=true
- Ansys, *Methodology Behind the Ansys-Adams Interface*: describes header metadata (date/version/title/units), body mass properties, reduced matrices, interface normal modes and constraint modes. https://ansyshelp.ansys.com/public/Views/Secured/corp/v251/en/ans_substr/advmeth2402.html

These references describe semantic content, not a complete public byte-level schema for every MNF producer/version.
